# 机械说明书模块

## 开发基线与隔离

远端基线：`origin/codex/pure-text-module-baseline` 的 `439e5854`（完成版纯文字稿模块）。首次开发曾误用另一条跟踪分支，已重放机械模块提交到此基线，保留最新纯文字稿与 PPT 功能。
开发分支：`codex/mechanical-thesis-title-only`。独立工作目录，不覆盖 F:\dropAi 的未提交改动。
`origin/main` 和 `origin/codex/dokiai-academic-frontend-v2` 属于不同分支，不用它们替换指定基线。

## 用户流程

`/mechanical-design` 默认打开机械说明书，可切回原结构方案。用户只输入题目，直接生成，不确认大纲、不上传任务书、不选模型。
第一章一个真实联网实物图；第二章结构图和装配结构；第三章原生公式和受力图；第四章四张不同零件图；第五章三维总装、二维总装、网格、两组应力/位移云图；第六章总结。
合计 15 个插图位置，只有图 1-1 使用检索，其余 14 张调用既有图片服务。网页图片及检索返回的直接图片地址均支持；已有视觉模型核验同类实物，拒绝目录图、渲染图及不相关零件。未找到实物图时保留其他成果并允许重试，不用生成图片冒充实物照片。
无封面、诚信声明、流程图、参考文献或资料来源段。来源 URL 保存在服务端任务记录，不写入论文或前端。云图采用灰白视口、单模型、坐标轴、约束和载荷箭头、右侧彩虹色标的定性分析版式，不编造有限元求解数据。方法小节保留一次简短的方法说明。

统一规划四个不同零件的材料、尺寸、孔位、载荷和解析计算。14 个二级小节为独立分支，共享 14 线程正文池；14 张生成配图共享 4 线程图片池。多个用户共享并发上限，不无限增加外部模型调用。每次最多两个工作流协调任务；同一个用户不重复启动进行中的论文。
正文目标 8050 字（统计汉字、字母、数字，不含摘要、标题、表格和公式），每节字数不合格自动重写最多三次，较短小节另行补自然段；整体偏短/偏长会定向调整小节，最终仅接受 6000—9000 字。不截断段落凑上限，不复制填充段落。最终摘要根据实际正文重新生成，不把规划中的仿真成果说法直接搬入摘要。

## 存储、权限与计费

不新增数据库、表或列。复用 `document_job`，`source_feature=MECHANICAL_PAPER`，结构化任务快照存入已有 LONGTEXT/CLOB 的 `paragraphs_json`。
图片和 DOCX 保存到持久目录 `mechanical.paper.output-dir`（默认 `data/mechanical-papers`），部署时此目录必须作为持久卷保留。
每个任务完成后短事务更新快照；网络调用不持有行锁。所有任务读取、重试、图片和下载验证所属用户。
浏览器只缓存账号对应任务 ID，正文状态以服务端为准。请求断线自动重连；服务重启后提示继续生成，复用完成的文字和图片，不重新调用已成功任务。
生成成功时在短事务内锁定任务行、使用独立 MECHANICAL_PAPER 定价并登记完成与扣费；重试不重复扣费。失败不扣费、下载不扣费。机械说明书、纯文字稿（WRITING_DOCX）、PPT（PPT_GENERATE）本次统一 300 积分/篇。复用已有 feature_pricing 增加机械说明书价格行，旧纯文字稿和 PPT 价格在首次升级时同步；不影响 DOCX_GENERATE 等其他功能。之后管理员明确改价不会因重启被覆盖。
纯文字稿原有“40 + 章节×8 + 图表×2”的实际扣费公式已移除，生成入口使用 WRITING_DOCX 价格。PPT 继续走原有成功后扣费和任务领取保护；增幅美化仍为独立操作，按原规则收取基础稿实扣积分的二分之一，不把它重复当作一篇生成收取 300 积分。

## 模型与桌面配置

正文：原有 MatrixDesignService 配置，不更换模型。
联网：原查文献模块的 DoubaoWebSearchProvider / Responses API / web_search 工具，增加专用实物图页面查询，不执行文献检索。
图片：原 DoubaoImageProvider。禁止缺配置时把正文模型当作生图模型调用。
新增只读桌面环境加载器，仅读取 `%USERPROFILE%\Desktop\.env` 或 `桌面\.env` 中 DOUBAO_ 开头键；系统环境变量和启动参数优先，日志不输出密钥。

用户于 2026-10-04 授权自行选择火山方舟图片模型并使用桌面测试密钥，并确认开通 Seedream 5.0 Flash。重新调用已成功返回 2496×1664 图片，目前采用 `doubao-seedream-5-0-flash-260915`。此前 4.0、5.0 Pro 也已探针实测，但不作为默认模型。已在桌面 .env 补充以下非密钥配置，原密钥保持不变：

```dotenv
DOUBAO_IMAGE_ENABLED=true
DOUBAO_IMAGE_MODEL=doubao-seedream-5-0-flash-260915
DOUBAO_IMAGE_BASE_URL=https://ark.cn-beijing.volces.com/api/v3
# 或直接设置 DOUBAO_IMAGE_ENDPOINT=<完整 /images/generations 地址>
DOUBAO_IMAGE_SIZE=2K
DOUBAO_IMAGE_WATERMARK=false
DOUBAO_IMAGE_TIMEOUT_SECONDS=180
DOUBAO_WEB_SEARCH_ENABLED=true
```

没有配置图片模型时前端显示“Doki 图片服务尚未配置”，不能触发一个注定失败且可能产生费用的任务。前端及本模块错误提示不展示底层厂商和模型名。图片接口采用方舟单图参数，不使用旧的 n 参数；5.0 Pro/Flash 不传其不支持的 sequential_image_generation 参数。支持参考图输入，云图使用用户提供的截图作为版式参考，不复制其中结构或求解数值。参考图 Base64 和密钥不记录到审计日志。正文仍使用原有模型，仅机械分支增加 thinking=disabled 和 JSON 输出约束；其他 MatrixDesignService 使用者参数保持原样。

## 例文表达优化（2026-10-11）

对照用户《复合传动码垛机结构设计论文》与实际生成夹具稿，收紧正文提示：少写零件百科、图纸作用、重复尺寸和泛化评价。各章按设计任务展开，第三章保留变量、单位、模型条件和判据；第四章强调配合与加工；第五章强调装配基准、尺寸链和载荷路径。5.5必须对应图5-6/7的同一功能件，不用定位销正文解释螺杆图片。方法边界保留5.3固定说明一次，不在其他小节反复说明生成过程，也不删除真实性限制。

总预算仍8050字，减少绪论、装配表达与总结篇幅，增加工况、方案取舍和计算依据。补字不再强制四段或两段，不得复述表格、尺寸或虚构结果填充。模型、图片数量、并发、计费与模板均不变。此变更只影响新生成正文，已有Word不自动改写；未重新付费调用模型生成整篇。

三维结构与总装图片改为SolidWorks建模视口视觉：正交等轴测、灰色实体、着色带边线、浅色背景；禁用RealView风格、金属纹理和照片级反光，不伪造软件窗口。此要求描述图片风格，不代表生成真实CAD模型。

2026-10-11实际调用模型生成同题试稿，三维图再次重画，正文约7917字。实物图联网检索两次失败，视觉审核样稿明确复用上次同题已核验实物照片，测试专用fixture不影响生产检索规则。节点/单元总数在正文与表格中也禁止虚构，5.3重写后再导出。第三章仍发现算术与判据矛盾，本轮是写法与配图试验，不是工程准确性验收；不得仅凭流程成功将样稿作为可制造图纸或已校核工程定稿。
