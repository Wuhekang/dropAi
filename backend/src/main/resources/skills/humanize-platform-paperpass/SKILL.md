# PaperPass降AI专用

本档只服务 PaperPass 降AI。它不是通用档，也没有普通模式和深度改写两档。不承诺检测百分比。

校准样本是降重狗订单 148903（PaperPass降AI专用）：同一段 186 字改成 195 字。要打散连续同形句，但事实不能换。竞品末句把“以确保技术方案具备可持续的实践价值”改成了“不足之处，有待于探究”，这是事实漂移，禁止照抄。

第二轮样本是降重狗订单 148945。竞品把“门诊科室”写成“门诊科目”，把“完整记录占比为91.5%”写成“被记录的有91.5%”。科室仍是科室，91.5% 仍是完整记录所占的比例。不得改成科目，也不得把完整记录占比写成仅仅“被记录”。

## 硬约束

1. 保留原意、论点、事实、条件、否定和因果关系。
2. 不得新增原文没有的数据、案例、引用、作者、年份、功能、缺口或结论。末句不得写成不足之处、有待于探究，也不得新写安全防护分析里的缺失。门诊科室不得写成门诊科目。完整记录占比为91.5% 必须保住“完整记录”和“所占比例”两层意思。
3. 不得输出标题、列表、多个版本或解释。
4. `[[DROP_AI_PROTECTED_数字]]` 必须逐字保留，顺序不变。
5. 代码、字段、接口、SQL、公式、图表编号和引用编号不要改成说明文。
6. 不得只做同义词替换，也不得沿原句逐句换词。允许段内改信息入口、拆句、并句并重组句组，不要求原句结构可还原。不得新增证据或遗漏独立信息。
7. 篇幅贴近原文，优先略短，控制在90%—108%，优先不超过105%，不要扩写。样本口径是 186 字到 195 字，仍在带内，不要再加长。不要删掉可持续的实践价值。若别处写 85%—130% 或允许超出，以本档为准。
8. 每个送入段落都要处理。模板段即使已经通顺也要重写入口和句组。没有模板骨架的锁定事实可以保留，不要为了制造差异改动准确内容。

## 专用策略

PaperPass 对连续同形句很敏感。比通用档更强的地方是：只要连续两句共用语法骨架，就必须改其中一句的起笔或句子边界。这是结构摇动，不是发明新判断。

- 禁止维持“对象 + 通过 + 动作 + 目的”的连续句。改信息分组，不要在原句上替换近义词。
- 软化研究腔起笔。近年来，随着……可以收成“近几年来，……迅猛发展”；本文旨在→本文试图；研究表明可以去掉，直接从已有的资源配置写起。
- 拉开句长。避免每句都在相近字数收住。
- 术语、编号、数据和保护片段的原值与出现顺序不变。运行效率、运营成本、数据安全、隐私保护都要留下。
- 门诊科室保持“科室”，不要写成“科目”。完整记录占比保持完整记录所占比例，91.5% 不能脱离“完整”单独写成“被记录的有91.5%”。
- 末句必须继续讨论数据安全与隐私保护，并保住“可持续的实践价值”。可以换近义说法，不得改成不足之处、有待探究，也不得新写本项目的安全分析缺口。
- 不要把短句统一扩成完整学术长句，也不要补段末总结。连续同形句即使读起来已经自然，也要改其中一句的起笔或句子边界。
- 不要使用“首先、其次、最后、综上所述、由此可见、具有重要意义”。

## 输出

只输出改写后的正文。
