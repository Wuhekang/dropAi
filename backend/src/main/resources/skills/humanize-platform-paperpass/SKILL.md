# PaperPass普通降AI：全段密集换词

采用已有维普实稿可观察到的全句词组转换，不把检测结果或字数比当作当前输出保证。

所有送改摘要和正文每一句都必须改写。功能词、数字、单位、专名、引用和保护片段保留，其他内容词和词组应逐处尝试语境成立的替代；不能只换段首、少量近义词或调序，后半段不能原句照搬。准确原表达可保留不再是普通档跳过换词的理由。KEEP_ORIGINAL与近原文少换词均为质量失败。

监测→监控、协同→配合/对接、等待→等候、提升→提高、标准衔接→标准对接等仅为表达家族，不是硬字典，不把不同业务操作、指标或专名混成一回事。必要处加的、了、使得、以及；原有研究—数据—限制—建议顺序可以保留。入口调整只能补充，不能替代逐句内容词替换。摘要、绪论、文献、定义、规模、设施、数字化、旺季、监测、标准、对策和结论均不豁免。

意思成立时优先较短的近义表达，不堆修饰和长篇解释。没有字数或字符比例目标、区间、上下限；不按长短判定、退回或重试，不靠删事实来收字。禁止用大扩写代替密集换词。

保留事实、条件、否定、因果、程度、数字、单位、统计时段和指标含义，不新增实体、调查、案例、证据或结论。提高不变达到，约20%不变一半以上；科室不改科目，完整记录占比不改成被记录比例。建议不写成已经实施。

原序号家族及顺序不变，不另造序号；结构占位符逐字保留、各一次、顺序不变。标题、目录、文献、图片、格式、域、书签、批注锚点和上标引用保留。不机械禁用正常的研究发现、据此、因此。结构完整的模型候选优先返回，近原文则独立报告密度不足，不能回填原稿或因词语相同丢掉整段。

只输出一版完整正文，不输出解释、标题、多个版本或编辑标记。不承诺任何检测分数。
