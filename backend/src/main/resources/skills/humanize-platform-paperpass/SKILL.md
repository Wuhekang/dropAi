# PaperPass普通降AI：轻量入口调整

以本地12.61%基线和六段人工轻调为表达参考，不把参考文件分数当作当前输出成绩，不承诺任何检测百分比。

## 写法

换原有信息入口、说清楚、略收篇幅。定义可从原有条件起笔；规模说明可先写货物或对象怎样周转，再接已有数据；数据分析可先提出原有矛盾，再说明平均改善与峰值限制；监测段可从要判断延误在哪一环起笔；数据复用先写减少重复填报这个已有目的；标准段先写现场需要可执行的指引，再接原措施、异常程序和记录。只用于匹配的原文，不套成统一模板，不复制参考论文的原句、实体或数据。

必要展开即可，不把每个名词都加修饰，不靠堆的、了、以及或同义复述拉长文字。不强制拆句，不一律短句，也不把所有句子都扩成长句。准确自然的词语可保留，后半段要实际处理，不只替换开头。

## 事实与结构

- 保留论点、事实、条件、否定、因果、程度及所有独立信息，不新增数据、案例、步骤、证据或结论，不把建议变成已完成结果。
- 数字、单位、统计时段、指标含义、专名、引用及保护片段保留；提高不变达到，主要不是不变根本不是，24小时不写成全天候。既有完整记录占比不能改成简单被记录比例，门诊科室不能改门诊科目。
- 标题、目录、图表、格式、域、书签、文献条目和引用由文档层保留。序号家族及顺序不变，全部结构占位符逐字保留、各一次、顺序不变。不禁用原有首先/其次/最后，也不另造序号。
- 不机械禁用研究发现、据此、因此等词，不用禁词清洗替代改写。所有送入的普通正文须实际改写，不以KEEP_ORIGINAL或失败回填冒充成果。

## 篇幅与返回

改写段约原文100%—130%仅作软参考；少一些可正常返回。不为凑比例扩写，不为凑改写密度扩到150%以上，不删掉必要事实、条件或限定。没有长度硬门槛，不因长度拒绝返回或自动按字数重试。

只输出本段一版完整改写正文，不给解释、新标题、多个版本或编辑标记。
