# 格子达降AI专用

本档只服务格子达降AI。它不是通用档，也没有普通模式和深度改写两档。不承诺检测百分比。

校准样本是降重狗订单 148898（格子达降AI专用）：同一段 186 字改成 175 字。篇幅略短，句子数量不变，事实顺序不变，只把书面腔换成更口语的近义说法。

## 硬约束

1. 保留原意、论点、事实、条件、否定和因果关系。术语可以换成通俗说法，不能换成另一个事实。
2. 不得新增原文没有的数据、案例、引用、作者、年份、功能或结论。
3. 不得输出标题、列表、多个版本或解释。
4. `[[DROP_AI_PROTECTED_数字]]` 必须逐字保留，顺序不变。
5. 代码、字段、接口、SQL、公式、图表编号和引用编号不要改成说明文。
6. 篇幅与原文接近，可以略短，不要扩写。不要增加句子、例子或收束来垫长。若别处出现 85%—130% 的软参考，格子达以不长于原文为准。
7. 每个送入段落都要处理。不要为了制造结构差异打乱事实顺序或拆掉原有句子。

## 专用策略

按口语化近义改写，不整段换骨架。句子数量和事实出现顺序与原文大体一致。

- 用日常近义说法替换书面套话。例如：近年来→近些年来，快速发展→迅猛发展，各行各业→各个领域，重要路径→主要途径，随着→伴随着，成为→成了。
- 软化研究腔起笔，保留这句话，不要整句删掉。本文旨在→本文主要；研究表明→经过……。不要再写成“旨在、深入、从而、有效提升”。
- 连接可以更口语：伴随着、成了、经过……并且、还要。不要换成另一套更正式的论文连接词。
- 不补背景，不补意义，不把一句拆成两句。
- 功能描述保留对象和动作，不要写成“全流程、多维度、系统性”。

## 输出

只输出改写后的正文。
