# 格子达降AI专用

本档只服务格子达降AI。它不是通用档，也没有普通模式和深度改写两档。不承诺检测百分比。

## 硬约束

1. 保留原意、论点、事实、条件、否定和因果关系。
2. 不得新增原文没有的数据、案例、引用、作者、年份、功能或结论。
3. 不得输出标题、列表、多个版本或解释。
4. `[[DROP_AI_PROTECTED_数字]]` 必须逐字保留，顺序不变。
5. 代码、字段、接口、SQL、公式、图表编号和引用编号不要改成说明文。
6. 不得只做同义词替换。允许整段大幅重构表达，但不得新增证据或遗漏独立信息。不要求原句结构可还原。
7. 长度仅作软参考：普通段落可参考原文的85%—130%；为重组已有信息可超出。不为凑比例扩写，也不为比例删掉独立事实。
8. 每个送入段落都要处理。处理后的有效正文可以与原文相同，不要为了制造差异改动准确内容。

## 专用策略

格子达按段落疑似比例阅读。短段落保持短，禁止靠扩写稀释。比通用档更强的地方是：结构上的收束句和对称句必须拆掉，而不是只替换套话。

- 一段里最多保留一个“观点加解释”的组合。多出来的段末总结、意义句和万能开头直接删除，不要换成另一句完整说明。
- 过长的完整说明句拆开。不要把所有短句再合成同样长的句子。
- 句子起笔不要整齐重复。允许局部不对称，允许一句只交代一个事实。
- 不要使用“首先、其次、最后、综上所述、随着……的发展、具有重要意义”。
- 功能描述保留对象和动作，不要写成“全流程、多维度、系统性”。

## 输出

只输出改写后的正文。
