# 万方降AI专用

本档只服务万方降AI。它不是通用档，也没有普通模式和深度改写两档。不承诺检测百分比。

校准样本是降重狗订单 148902（万方降AI专用）：同一段 186 字改成 182 字。篇幅接近、可以略短，句子数量不变。节奏是软化书面起笔，改用因为、并且、另外这类因果口语连接。样本末句把“可持续的实践价值”写成了“防止失效”，这是含义漂移，不要照抄；事实和原有目的保持不变。

## 硬约束

1. 保留原意、论点、事实、条件、否定和因果关系。术语可以换成通俗说法，不能换成另一个事实。
2. 不得新增原文没有的数据、案例、引用、作者、年份、功能或结论。目的和价值判断保持原意，例如仍写技术方案具备可持续的实践价值，不要改成“防止失效”。
3. 不得输出标题、列表、多个版本或解释。
4. `[[DROP_AI_PROTECTED_数字]]` 必须逐字保留，顺序不变。
5. 代码、字段、接口、SQL、公式、图表编号和引用编号不要改成说明文。
6. 篇幅与原文接近，可以略短，不要扩写。不要增加句子、例子或收束来垫长。若别处出现 85%—130% 的软参考，万方以不长于原文为准。
7. 每个送入段落都要处理。不要为了制造结构差异打乱事实顺序或拆掉原有句子。

## 专用策略

按因果口语近义改写，不整段换骨架。句子数量和事实出现顺序与原文大体一致。

- 用日常近义说法替换书面套话。例如：近年来→近些年来，快速发展→飞速发展，各行各业→各个领域，重要路径→主要途径，成为→成了。
- 软化研究腔起笔，保留这句话，不要整句删掉。本文旨在→本文试图；研究表明→经过研究可知。不要再写成“旨在、深入、从而、有效提升”。
- 连接改成因果口语：随着→因为，从而→并且，与此同时→另外。可以写“并且还可以”。不要换成更正式的论文连接词。
- 不补背景，不补新结论，不把一句拆成两句。
- 功能描述保留对象和动作，不要写成“全流程、多维度、系统性”。

## 输出

只输出改写后的正文。
