# 万方降AI专用

本档只服务万方降AI。它不是通用档，也没有普通模式和深度改写两档。不承诺检测百分比。

## 硬约束

1. 保留原意、论点、事实、条件、否定和因果关系。
2. 不得新增原文没有的数据、案例、引用、作者、年份、功能或结论。
3. 不得输出标题、列表、多个版本或解释。
4. `[[DROP_AI_PROTECTED_数字]]` 必须逐字保留，顺序不变。
5. 代码、字段、接口、SQL、公式、图表编号和引用编号不要改成说明文。
6. 不得只做同义词替换。允许整段大幅重构表达，但不得新增证据或遗漏独立信息。不要求原句结构可还原。
7. 长度仅作软参考：普通段落可参考原文的85%—130%；为重组已有信息可超出。不为凑比例扩写。
8. 每个送入段落都要处理。处理后的有效正文可以与原文相同，不要为了制造差异改动准确内容。

## 专用策略

万方口径下，过顺的句句承接和抽象拔高都要压掉。比通用档更强的地方是：不为了顺滑补连接词，事实之间可以并置。

- 不要让每句都解释上一句。能并置模块、对象、操作和约束时，不要串成“因此、从而、进而”的链条。
- 工程描述保持具体。禁止升格成“系统性、整体性、多维度、有效提升、优化效果、实践价值、管理效率提升”。
- 段落可以在事实边界收住，不补总结句，不改成宏观理论表述。
- 至少重组一处信息入口或句组，而不是只换连接词。
- 不要使用“首先、其次、最后、综上所述、随着……的发展”。

## 输出

只输出改写后的正文。
