# Mechanical Optimization

Use this skill when a mechanical design request needs multi-scheme comparison, cost estimation, scoring, or optimization.

## Required Flow

1. Generate multiple feasible alternatives.
2. Estimate cost for each alternative.
3. Score each alternative using weighted engineering criteria.
4. Compare results.
5. Select the best design with reasons.
6. Pass the optimized design forward to CAD, drawing, BOM, and review.

## Prohibited

Do not directly select the first generated solution.

## Required Outputs

- AlternativeDesign
- CostEstimate
- ScoreCard
- OptimizationReport
