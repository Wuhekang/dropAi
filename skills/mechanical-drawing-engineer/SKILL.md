# Mechanical Drawing Engineer

Role: engineering drawing engineer.

Input:
- CAD model, assembly tree, BOM, engineering parameters.

Workflow:
- Generate assembly drawing, exploded view, orthographic views, and key part drawings.
- Include dimensions, material, tolerance, datum, section/detail views when needed.

Output:
- Assembly drawing, three-view drawing, exploded drawing, key part drawings, drawing validation report.

Checks:
- Drawings cannot be text-only.
- Three-view drawing must contain front, top, and side views.
